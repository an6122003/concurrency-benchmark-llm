What we measure

Peak throughput is a marketing number. Usable throughput is a team decision. We record both.

Comfortable users

How many people can chat at once before speed, latency, or reliability breaks down.

Tokens per second

Aggregate server throughput and per-user speed, at every concurrency level from 1 to 16.

Time to first token

The metric you feel. Streamed TTFT and P95 latency, because averages hide the bad days.

Memory headroom

VRAM after load and under load — whether that 30B model truly fits, or just barely boots.

Price to performance

Tokens per second per dollar, and hardware cost per comfortable user. Buyers' math, done.

How it works

Three steps from your GPU to the leaderboard. No accounts, no cloud — just JSON.

01

Serve a model locally

LM Studio, Ollama, or llama.cpp server — any OpenAI-compatible endpoint on your own hardware.

02

Run the benchmark

One Python script simulates 1–16 concurrent users and records every token, timing, and failure.

03

Import & compare

Drop the results.json into the database and see exactly where your setup lands.
